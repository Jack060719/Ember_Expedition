# 餘燼遠征 · Ember Expedition

直向單指操作的離線冒險。拖曳移動，普攻與技能自動施放；探索主線、走位作戰、踩板解謎，再用火種建設營地。

## iPhone 安裝

1. 用 Safari 開啟發布網址，依私人網站的提示登入。
2. 分享 → 加入主畫面。
3. **從主畫面圖示再次開啟**，保持連網，直到左上角顯示「已可離線遊玩」。
4. 開啟飛航模式並關閉 Wi-Fi，重新開啟遊戲確認。

Safari 分頁和主畫面 App 的儲存資料可能不同，請在主畫面版本開始正式遊玩。遊戲內「設定與存檔」可匯出／匯入 JSON 備份；清除網站資料會失去本機進度。

下載未完成時，點左上角離線狀態，查看原因並選「重新下載缺少的內容」。已安裝版本會補回缺檔；首次安裝失敗則重新下載，不影響遊戲存檔。若顯示有新版本，完成或撤退結束目前遠征後，在同一視窗套用更新。

移動採用跟隨手指的浮動搖桿：輕推慢走、拉遠快走，鬆手或移出遊戲畫面會停止。長距離拖曳後不必拖回最初按下的位置才能轉向。

## 首版內容

- 3 章、6 次主線遠征；每次包含 8 個房間（6 場戰鬥、1 個可略過的寶庫、1 場最終守衛或首領）。
- 3 種武器、18 種升級、6 種普通敵人、3 個具有不同攻擊模式的首領。
- 9 個可解的符文踏板題目；提示、重置與略過不需要網路。
- 3 項營地設施、普通／困難重玩、每局以種子重新排列遭遇。
- 主線首次通關以 90–120 分鐘為調整目標，實際時間取決於路線、失敗與配裝；仍需實玩校準。
- 暫停或切到背景會停止戰鬥；程序被關閉後從房間入口恢復，可能重打當前房間。谜題逐步保存。
- 失敗保留一半本局火種，保留所有永久成長；撤退帶回已收集火種。

## 開發與驗證

需要 Node.js 22.18 以上。

```sh
npm ci
npm run dev -- --port 5173 --strictPort
npm test
npm run build
npm run preview -- --port 4173 --strictPort
npx playwright install chromium
npm run test:browser
npm run test:arena
npm run test:offline
```

瀏覽器測試需要 4173 的正式建置預覽；機制測試需要 5173 的開發伺服器。報告與畫面輸出到未追蹤的 `artifacts/`。測試使用獨立無痕環境和本遊戲的匯入介面，不讀取個人瀏覽器資料。

`src/core.ts` 為規則與存檔格式；`src/arena.ts` 為 Phaser 場景、碰撞和單指操作；`src/main.ts` 為營地、主線與存檔操作。`scripts/build-offline.mjs` 將正式輸出全部檔案加入具內容版本的 Service Worker 快取。所有遊玩依賴都在同一來源，無執行時 CDN、帳號 API 或線上關卡。

本機檢查涵蓋：規則測試、Chromium 手機尺寸與桌面畫面、真正斷網後的新頁面啟動、存檔續玩、備份匯出及無效匯入、結算不重複發獎、武器／首領／解謎機制。這些不等於 iPhone Safari 實機測試。

離線回歸測試另涵蓋缺檔重試、登入頁防誤存、首頁正規化與版本更新；觸控測試涵蓋實際觸控事件、多指干擾、取消與移出畫面。可安裝 Playwright WebKit 後執行 `npm run test:offline -- --webkit`；Windows WebKit 的 `setOffline` 會使最小快取頁面也出現內部錯誤，因此此模式改為中斷伺服器連線驗證快取，不等於 iPhone 飛航模式測試。

待實機驗證：iOS 17+ Safari／主畫面、長時間發熱與耗電、兩小時連玩及相隔七天的離線重開。系統持久儲存申請不保證網站資料永遠不會被清理。原生 WebMCP 執行環境目前未連線，兩個選用介面的實際註冊尚未驗證。

## 美術來源

使用內建 ImageGen 與 agent-sprite-forge 的 generate2dsprite / generate2dmap 技能製作。`public/assets/` 為執行時素材，`assets-source/` 保留七份原圖、創作提示、圖集契約與 QC 紀錄。沒有以程式圖形取代角色或場景；程式只繪製操作提示、攻擊預警、血條等功能性圖形。

主角圖集為 4×4、每格 128 px，方向依序下／左／右／上；敵人與物件圖集為 3×3、每格 128 px。場景只烘焙地面，提燈、機關、寶箱與角色分開繪製，碰撞範圍由場景資料定義。

部署為 Sites 私人靜態網站，`.openai/hosting.json` 對應同一專案。發布時將 `dist/` 打包；不將美術原圖、測試存檔或私人憑證放入公開遊戲輸出。
